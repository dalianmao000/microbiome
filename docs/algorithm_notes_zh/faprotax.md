# FAPROTAX 算法说明

## 概述

FAPROTAX 是一个数据库及 Python 脚本，用于基于已发表的培养物和功能参考文献对原核生物分类群进行功能注释。

## 主要特点

### 1. 基于培养物的注释

FAPROTAX 基于已发表的细菌和古菌培养物构建功能注释，为特征明确的分类群提供更可靠的功能预测。

### 2. 功能类别

FAPROTAX 覆盖重要的生物地球化学循环：
- **氮循环**：硝化、反硝化、固氮
- **碳循环**：发酵、甲烷生成
- **硫循环**：硫酸盐还原

### 3. 分类学注释

与 PICRUSt2 使用系统发育定位不同，FAPROTAX 需要对输入序列进行分类学注释。

## 局限性

1. **培养偏向** —— 仅包含有培养代表的分类群
2. **覆盖范围有限** —— 主要为环境细菌
3. **依赖分类学注释** —— 需要准确的分类学分类

## 面试要点

- "FAPROTAX 基于已发表的培养物，因此对已知细菌有良好的验证基础"
- "它覆盖了重要的功能群，如氮循环和碳循环微生物"
- "权衡在于它可能会遗漏未培养或特征较少的分类群"
