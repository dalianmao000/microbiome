# LEfSe 算法笔记

## 概述

LEfSe（Linear Discriminant Analysis Effect Size，线性判别分析效应量）是一款用于高维生物标志物发现与解释的工具。它能够识别出不同组之间具有差异丰度的特征。

## 算法步骤

### 1. Kruskal-Wallis 检验（多组比较）

Kruskal-Wallis H 检验是一种非参数方法，用于检验样本是否来自同一分布。

**为什么选择 Kruskal-Wallis 而非 ANOVA？**
- 微生物组数据通常不服从正态分布（存在大量零值、偏态分布）
- Kruskal-Wallis 不需要假设正态性

**数学公式：**
$$H = \frac{12}{N(N+1)} \sum_{j=1}^{g} \frac{R_j^2}{n_j} - 3(N+1)$$

其中：
- $N$ = 样本总数
- $g$ = 组数
- $R_j$ = 第 $j$ 组的秩和
- $n_j$ = 第 $j$ 组的样本数

### 2. Wilcoxon 检验（两两比较）

对于两组比较，Wilcoxon 秩和检验用于评估两个分布是否存在差异。

### 3. 线性判别分析（LDA）

LDA 估计每个特征对组间分离的效应量。

**核心洞察：** LDA 同时提供了统计显著性 AND 生物相关性，通过效应量来体现。

## 关键参数

| 参数 | 默认值 | 描述 |
|-----------|---------|-------------|
| alpha | 0.05 | KW 检验的显著性水平 |
| lda_threshold | 2.0 | 报告所需的最小 LDA 分数 |
| min_abundance | 1e-6 | 最小平均丰度 |
| min_prevalence | 0.1 | 样本间的最小检出率 |

## 局限性

1. 零膨胀数据可能影响 p 值
2. LDA 假设多元正态性（这一假设常常不成立）
3. 多重检验校正至关重要

## 面试要点

- "LEfSe 采用两步法：首先是统计显著性检验，然后通过 LDA 估计生物相关性"
- "选择 Kruskal-Wallis 而非 ANOVA，反映了微生物组计数数据的非正态特性"
- "LDA 阈值为 2.0 意味着该特征在两组间的对数比值在 log10 尺度上至少为 2"
