# Alpha多样性算法笔记

## 概述

Alpha多样性衡量单个样本内的多样性。关键指标包括：观察特征数、Shannon指数、Chao1指数和Simpson指数。

## 关键指标

### 观察特征数 (Observed Features)
简单地统计样本中非零特征(OTUs/物种)的数量。

### Shannon指数
$$H = -\sum_{i=1}^{S} p_i \log(p_i)$$

其中 $p_i$ 是特征 $i$ 的比例。

### Chao1丰富度估计器
$$S_{chao1} = S_{obs} + \frac{n_1(n_1-1)}{2(n_2+1)}$$

其中 $n_1$ 是单例数量，$n_2$ 是双例数量。

### Simpson指数
$$D = 1 - \sum_{i=1}^{S} p_i^2$$

## 指标选择指南

| 指标 | 敏感性 | 最佳用途 |
|------|--------|----------|
| Observed | 样本量 | 丰富度 |
| Shannon | 稀有物种 | 一般多样性 |
| Chao1 | 低频物种 | 稀有物种 |
| Simpson | 优势物种 | 均匀度 |

## 面试要点

- "Alpha多样性衡量样本内多样性"
- "Chao1是一个考虑未观察物种的丰富度估计器"
- "Simpson指数对优势物种赋予更高权重，而Shannon对稀有物种更敏感"
