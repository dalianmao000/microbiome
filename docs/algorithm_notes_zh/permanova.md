# PERMANOVA 算法笔记

## 概述

PERMANOVA（置换多元方差分析）是一种非参数多元统计检验方法，用于比较生态数据中的组间差异。

## 数学公式

$$F = \frac{SS_{between}}{SS_{within}} \cdot \frac{df_{within}}{df_{between}}$$

其中：
- $SS_{between}$ = 组质心之间距离的平方和
- $SS_{within}$ = 组内距离的平方和

## PERMANOVA 工作原理

1. 从距离矩阵计算观测到的 F 统计量
2. 随机置换组别分配
3. 每次置换后重新计算 F 统计量
4. 将观测到的 F 值与零分布进行比较

## 微生物组分析中的优势

1. **非参数方法** - 不需要假设正态分布
2. **适用于任何距离度量** - 可使用 Bray-Curtis、UniFrac 等
3. **多元分析** - 检验整体群落差异

## 局限性

1. **需要足够的置换次数** - 以获得准确的 p 值
2. **可能受离散度影响** - 类似于 ANOVA 的假设条件
3. **在异质性离散情况下** - 可能会出现 Type I 错误膨胀

## 面试要点

- "PERMANOVA 检验各组在整体群落组成上是否存在差异"
- "其原理是比较组内距离与组间距离"
- "p 值通过置换获得，因此是非参数方法"
