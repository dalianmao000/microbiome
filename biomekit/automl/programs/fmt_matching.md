# program.md - Donor-Recipient Matching for FMT Efficacy Prediction

> **场景**: 菌群移植(FMT)供体-受体匹配算法
> **适用**: 精准菌群移植治疗平台

---

## 🔬 研究目标

构建供体-受体菌群匹配度算法,预测菌群移植后临床响应概率,
支持"个性化供体推荐"业务场景。

**评价指标**: 多目标优化 - PR-AUC(0.5) + Top-K准确率(0.3) + 校准度(0.2)

---

## 📊 数据规范

- 供体数据: 宏基因组物种/功能谱 + 临床元数据 (年龄, 饮食, 健康状态)
- 受体数据: 移植前菌群谱 + 疾病表型 + 用药史
- 标签: 响应 (1=临床改善, 0=无改善), 定义依据[明确临床标准]
- 样本对: (donor_i, recipient_j) → outcome, 需处理配对依赖性

---

## 🧭 搜索空间 (agent可探索策略)

### 匹配度计算策略
- [x] 距离度量: Bray-Curtis, Jaccard, 距离度量选择
- [x] 功能对齐: 代谢通路丰度的余弦相似度
- [x] 关键菌共享: 预定义"有益菌列表"的Jaccard重叠率
- [x] 学习度量: Siamese-style匹配表示学习

### 预测模型
- [x] `rf` - RandomForest (处理高维稀疏特征)
- [x] `xgb` - XGBoost (高精度需求)
- [x] `lr` - LogisticRegression (可解释性优先)
- [x] `svm` - SVM (小样本场景)

### 样本处理策略
- [x] 类别不平衡: class_weight调整 (FMT响应样本通常不平衡)
- [x] 配对依赖: GroupKFold按受体ID分组

---

## 📏 评估函数 (临床导向)

### 主指标 (临床导向)
- PR-AUC (因正样本稀疏, 优于ROC-AUC)

### 业务指标
- Top-K推荐准确率: 若为每个受体推荐K个供体, 真实有效供体是否在Top-K中
- 校准度: 预测概率与实际响应率的一致性 (Brier score)

### 综合得分
```
score = 0.5×PR_AUC + 0.3×Top3_Accuracy + 0.2×(1-Brier)
```

---

## 🧬 领域约束规则

1. **[必须]** 匹配算法需考虑"生态位兼容性": 受体基础菌群不能完全排斥供体菌
2. **[必须]** 模型输出需包含"不确定性估计" (如预测区间), 支持临床决策
3. **[禁止]** 使用受体移植后数据作为输入 (避免信息泄露)
4. **[建议]** 优先选择可解释的匹配规则: "若受体缺乏XX菌, 优先匹配富含该菌的供体"

---

## 🔄 迭代策略

- 优先优化"匹配度计算"模块, 再优化"预测模型"
- 引入"对抗验证": 检查供体/受体分布差异, 避免模型学习批次效应
- 每10次迭代进行一次"策略回顾": agent需总结哪些策略有效/无效

---

## 📤 输出规范

- `matching_function`: 代码片段或公式描述
- `feature_importance`: 哪些供体/受体特征对预测最关键
- `case_study`: 选取3个典型样本, 展示匹配逻辑与预测结果
- `clinical_note`: 用非技术语言描述"该模型如何辅助医生决策"

---

## 🚫 终止条件

- PR-AUC ≥ 0.7 且 Top3准确率 ≥ 0.6
- 或 达到80次迭代上限
- 或 业务方确认当前模型可进入小规模临床验证
