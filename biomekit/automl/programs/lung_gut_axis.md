# program.md - Lung-Gut Axis Respiratory Disease Prediction

> **场景**: 肠-肺轴驱动的呼吸道疾病风险预测
> **适用**: 肠道微生物组与呼吸系统关联研究 (哮喘/COPD/呼吸道感染)

---

## 🔬 研究目标

基于肠道微生物组+临床数据,构建哮喘/COPD/呼吸道感染等疾病的早期风险预测模型,
支撑"肠道干预改善呼吸健康"的微生态诊疗方案。

**评价指标**: 多目标优化 - 性能(0.5) + 可解释性(0.3) + 业务可操作性(0.2)

---

## 📊 数据规范

- 核心数据:
  - 肠道宏基因组: 物种/功能/菌株水平丰度
  - 临床表型: 肺功能指标(FEV1/FVC), 炎症标志物(CRP, IL-6), 用药史
  - 协变量: 年龄, 性别, 吸烟史, 抗生素使用, 地域(多中心)
- 标签定义:
  - 二分类: 疾病组 vs 健康对照 (用于筛查)
  - 有序多分类: 疾病严重程度分级 (轻/中/重,用于分层干预)
  - 连续型: 肺功能下降速率 (用于疗效监测)
- 数据分割策略:
  - 按"医疗机构"分层抽样,确保训练/测试集无中心泄露
  - 保留独立外部验证集

## 🧭 搜索空间 (agent可探索策略)

### 特征工程: 肠-肺轴特异性
- [x] `lefse`, `rf_importance`, `lasso`, `ancom`, `wilcoxon` (标准特征选择)
- [x] 已知轴相关菌筛选: 优先保留文献报道的"肠-肺通讯"菌属
  - 促炎风险菌: Enterobacteriaceae, Streptococcus
  - 保护性菌: Faecalibacterium, Bifidobacterium, Lactobacillus
  - 代谢功能菌: 丁酸产生菌 (Roseburia, Anaerostipes)
- [x] 功能通路聚合: 聚焦"免疫调节"相关KEGG通路
  - LPS生物合成, SCFA代谢, 色氨酸代谢, 胆汁酸转化

### 模型策略
- [x] `rf` - RandomForest (n_estimators∈[50,200], max_depth∈[3,10])
- [x] `xgb` - XGBoost (n_estimators∈[100,300], max_depth∈[3,8], learning_rate∈[0.01,0.3])
- [x] `lr` - 正则化逻辑回归 (优先可解释性)
- [x] `mlp` - MLP (hidden_layer_sizes∈[(64,),(128,),(64,32)])

### 多中心适配策略
- [x] 批次效应校正: ComBat-Seq风格 (在特征工程前)
- [x] 域自适应: 对抗训练减少中心间分布差异 (预留接口)

## 📏 评估函数 (prepare.py实现, 业务导向)

### 主指标 (临床价值优先)
- 早期筛查场景: PR-AUC @ 高特异度区间 (Specificity ≥ 0.9)
- 分层干预场景: 加权Kappa (评估严重程度分级一致性)
- 疗效监测场景: 预测值与真实值的Spearman相关 + MAE

### 业务增益指标
- 可解释性得分: 模型输出的Top-10特征中, ≥5个有肠-肺轴文献支持
- 临床可操作性: 推荐干预靶点 (菌/通路) 有文献或临床证据支持
- 跨中心泛化: 在外部验证集性能衰减 ≤ 20%

### 综合得分公式
```
score = 0.5×Primary_Metric + 0.3×Interpretability + 0.2×Business_Actionability
```

## 🧬 领域约束规则 (硬约束)

1. **[必须]** 特征选择过程需排除"呼吸样本污染"的肠道菌 (如口腔常见菌)
2. **[必须]** 若模型用于临床辅助决策,必须输出预测置信区间
3. **[禁止]** 使用抗生素使用后<4周的样本 (菌群未恢复,干扰因果推断)
4. **[建议]** 优先选择"可干预"靶点: 有文献支持的可培养/可移植菌株

---

## 🔄 迭代策略

- 阶段1 (1-15次): 单中心数据验证,快速筛选有效特征策略
- 阶段2 (16-40次): 多中心泛化优化,重点解决批次效应
- 阶段3 (41+次): 临床可解释性强化,输出"医生可读"的报告模板
- 探索机制: 每10次迭代生成"策略回顾报告",人工审核是否需调整搜索空间

---

## 📤 输出规范 (对接业务系统)

每次实验必须记录:
- `model_card`: 模型类型+关键参数+适用人群描述
- `biomarker_report`: Top-20标志物列表 (菌名+功能+文献支持度)
- `clinical_summary`: 用非技术语言描述"该模型如何辅助呼吸科医生决策"
- `deployment_checklist`: 推理所需最小数据字段,预计单样本推理时间

## 🚫 终止条件

✅ 达到以下任一条件即可终止并进入业务评审:
- 外部验证集 PR-AUC ≥ 0.75 且 可解释性得分 ≥ 0.6
- 识别出3+个有文献支持的干预靶点,且有初步机制假设
- 临床验证团队确认可进入小规模临床验证

❌ 以下情况需人工介入调整program.md:
- 连续20次迭代综合得分提升 < 0.005
- agent生成大量"统计显著但无生物学意义"的特征组合
- 多中心泛化性能持续低于单中心性能30%以上
