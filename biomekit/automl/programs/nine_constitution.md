# program.md - TCM Nine-Constitution Microbiome Profiling

> **场景**: 中医九体体质微生态分型与个性化干预推荐
> **适用**: 中医体质与肠道微生物组关联研究

---

## 🔬 研究目标

构建"中医九体体质-肠道微生物组"映射模型,实现:
1. 基于菌群数据的体质智能辨识 (辅助九体问卷)
2. 体质特异性菌群干预方案推荐
3. 体质-疾病风险关联挖掘 (支撑微生态预防医学)

**评价指标**: 多目标优化 - 准确率(0.4) + 业务匹配(0.3) + 中医理论一致性(0.2) + 可解释性(0.1)

---

## 📊 数据规范

- 核心数据:
  - 肠道16S/宏基因组: 标准化流程产出
  - 九体体质标签: 标准化问卷评分 (9维连续值+主导体质分类)
  - 临床扩展: 代谢指标 (血糖,血脂), 免疫指标, 生活方式问卷
- 标签处理策略:
  - 方案A (分类): 主导体质 (9分类) → 用于体质辨识
  - 方案B (回归): 9维体质评分 → 用于精准分型
  - 方案C (多标签): 兼夹体质识别 (如"气虚+湿热") → 更贴合临床实际
- 数据增强:
  - 对稀有体质 (如特禀质) 进行过采样/合成
  - 引入"体质演变"时序数据 (若用户有多次检测记录)

## 🧭 搜索空间 (agent可探索策略)

### 特征工程: 中医理论引导
- [x] 体质相关菌先验库: 加载预定义的"体质-菌群"文献映射
  - 气虚质: Bifidobacterium↓, Clostridium cluster IV↓
  - 湿热质: Proteobacteria↑, Escherichia/Shigella↑
  - 平和质: 菌群多样性高,功能冗余性强
- [x] 功能导向聚合: 按"中医证候相关通路"分组
  - 气虚: 能量代谢 (TCA循环, 氧化磷酸化)
  - 湿热: 炎症相关 (LPS合成, 氮代谢)
  - 痰湿: 脂质代谢 (胆汁酸, 脂肪酸β氧化)
- [x] 网络特征: 构建"菌-菌共现网络",提取模块特征
- [x] 标准特征选择: `lefse`, `rf_importance`, `lasso`, `ancom`, `wilcoxon`

### 模型策略
- [x] `lr` - 多标签逻辑回归 (优先可解释性)
- [x] `rf` - RandomForest (处理多标签/兼夹体质)
- [x] `xgb` - XGBoost (高精度需求场景)
- [x] `mlp` - MLP (层次表示学习)

### 干预推荐模块
- [x] 菌库匹配: 将模型识别的"体质缺陷菌"映射到可用菌株库
- [x] 方案生成: 基于体质+疾病风险, 推荐"菌+益生元+生活方式"组合

## 📏 评估函数 (中医现代化+商业价值双导向)

### 主指标
- 体质辨识准确率: Top-1准确率 + Top-3召回率 (临床允许兼夹体质)
- 评分预测误差: 9维体质评分的平均MAE + 相关系数
- 兼夹体质识别: F1-score @ 多标签场景

### 业务价值指标
- 干预匹配度: 推荐方案中, ≥70%菌株有文献/临床证据支持
- 中医理论一致性: 模型输出的"关键菌-体质"关联, ≥60%有经典文献支持
- 用户可理解性: 生成的体质报告, 经中医师盲评得分 ≥ 4/5

### 综合得分
```
score = 0.4×Accuracy + 0.3×Business_Match + 0.2×TCM_Consistency + 0.1×Explainability
```

## 🧬 领域约束规则 (中医理论硬约束)

1. **[必须]** 模型需支持"兼夹体质"输出,避免强制单分类违背中医理论
2. **[必须]** 推荐干预方案需符合"辨证施治"原则: 如湿热质不推荐温补菌株
3. **[禁止]** 使用与中医理论明显冲突的特征 (如"某菌直接决定体质"的简化论)
4. **[建议]** 优先选择"药食同源"相关菌株,便于开发健康产品
5. **[伦理]** 体质报告需包含"仅供参考,需专业医师解读"的免责声明

## 🚫 终止条件 (产品化导向)

✅ 达到以下任一条件可进入产品评审:
- 体质辨识Top-1准确率 ≥ 0.65 (9分类) 且 中医师盲评 ≥ 4分
- 推荐方案匹配度 ≥ 0.8 且 用户模拟测试满意度 ≥ 4/5
- 产出2+个有论文潜力的新发现, 获领域专家合作确认

❌ 需人工调整的情况:
- 模型过度依赖单一菌种,违背"整体观念"中医原则
- 推荐方案与可用菌株匹配度持续 < 0.5
- 稀有体质预测性能显著低于常见体质 (需调整采样策略)
